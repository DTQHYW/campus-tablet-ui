# Design Spec — 校园日常

## 项目定位

- 项目名称：校园日常
- 形式：角色卡（世界书内嵌）
- 主题：校园日常 / 角色扮演
- 体验目标：日常养成——玩家扮演一名普通男学生，在校园中与多位女性角色互动，通过日常事件推进关系
- 情感落点：轻松趣味——多元角色个性碰撞带来趣味互动，日常中穿插温馨、心跳、搞笑等多层次情绪

## 世界观概念

- 世界基调：现代高中校园，真实架空
- 核心规则：现实世界规则，无超自然元素；校园生活为主舞台
- 时代/舞台：现代，某市普通高中，以教室、走廊、医务室、校园周边为主要场景
- 现实性基线：真实架空——以现实校园生活为基础，允许适度戏剧化巧合，但不引入超自然或科幻设定
- 世界整体氛围：稳定日常——校园生活为底色，角色间的张力关系构成日常中的波折与趣味
- 特殊设定：无；班级设定为普通高中班级，角色分布于同班或校内不同位置（医务室等）

- 内容分级：**SFW（全年龄向）**

- 性向与关系结构：异性向，多角色并行（非后宫争斗，各自独立线）

- 暧昧尺度上限：心跳感、脸红、牵手、撒娇等日常暧昧，不超越

## 剧情设计

### 整体结构

日常养成制——无强制主线剧情，以校园日常事件为单元，玩家通过与各角色互动推进关系。已攻略角色从高好感度日常出发深化关系，未攻略角色从初始状态（对立/疏远/初步互动）逐步推进。

### 关系推进逻辑

- **已攻略角色**：日常亲密互动中展现更深层的性格面，关系从"已建立"向"更深入"发展
- **未攻略角色**：通过日常事件（同桌争执、班级活动、医务室偶遇、被欺负/保护等）逐步解锁更多互动，好感度累积推动关系阶段变化
- **角色弧光**：成长向——每个角色随互动深入展现成长或反差面（如黑塔的傲娇软化、薇薇安的狡黠浮现、美游的自卑改善、露西的逞强暴露等）

### 角色成长方向要点

- 董壹萌：从占有欲到学会分享
- 黑塔：从高冷防备到坦诚在意
- 薇薇安：天然呆面具下的狡慧逐渐显现
- 路曼曼：从较劲到理解
- 苏颜：打破沉默距离
- 倩倩/若若：闯祸/懒散下的责任感与直觉
- 露西：逞强外壳碎裂后的真实
- 雅雪：疯丫头外表下的敏感
- 花火：恶作剧背后的真实想法
- 美游：从自卑到被看见
- 美羽：懒散下的关怀深度

### 动态追踪需求

- 每个角色多维度状态（好感度、关系等级、攻略状态等）
- 即时反馈：每次互动后状态即时变化，玩家能快速感知进展
- 关键事件标记：触发特定事件后记录，影响后续互动走向

### 暴露时机与控制

- 无复杂主线剧情，不需要阶段性揭示控制
- 角色反差面随好感度提升自然展现，由 MVU 状态驱动
- 各角色线路独立并行，不设强制推进顺序

## 风格意向

- 叙事视角：第二人称（"你"）
- 语言风格：口语化、轻松
- 文学密度：口语轻量，日常对话为主
- 描写侧重：对话为主，动作与心理描写为辅，环境描写点到即止
- 节奏偏好：轻快推进，日常单元式
- 情绪基调：多元情绪——以轻松趣味打底，随角色性格不同带来温馨、心跳、搞笑、感动等层次变化
- 风格参考：无特定参考

## 开场构思

- 开场形式：**多开场选择**——角色分别开场，每个开场对应不同角色的首次互动场景
- 开场信息密度：渐进揭示——开场只引入当前场景与对应角色，其他角色随日常推进自然登场
- 首步引导：弱引导——开场给出情境与角色，玩家自由选择互动方式
- 与主线衔接：无主线，开场即为日常起点，各开场平行可选

### 开场候选场景

1. **董壹萌开场**：早晨妹妹叫起床/一起上学，展现兄妹日常
2. **黑塔开场**：收到黑塔的测试通知，前往辅导
3. **薇薇安开场**：青梅竹马来找你一起上学，天然呆互动
4. **路曼曼开场**：到教室坐下，同桌的火药味互动
5. **美羽开场**：身体不适去医务室，遇到大姐姐

> 具体开场数量与内容在 tavern-cards 创作规划阶段确定。
